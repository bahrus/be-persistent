be-persistent → GitHub Gist

Both fields below are enhanced with 💾 and a gist:// USL. On change (blur / Enter) the value is written to one file inside a single secret gist; on reload it is read back. api.github.com sends permissive CORS, so this works from any origin with no proxy.

2 · Persisted fields

Type something, click outside the field (fires change), then reload the page — the values come back from the gist. An empty field writes nothing (GitHub rejects a gist file with empty content), so the gist is created only once you enter a real value.
