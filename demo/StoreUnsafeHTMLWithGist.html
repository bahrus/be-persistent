2 · Source — gist://unsafe-html-demo/markup.html

Plain of value — an ordinary be-persistent rule; a <textarea>'s value is always text, so it never needs unsanitizedInnerHTML. The field starts empty, so nothing is written until you type and leave it — no doomed create on load. Typing fires input on every keystroke; this rule uses on focusout instead so one gist PATCH is sent when you leave the field, not one per key. Reload the page — the text comes back from the gist.

3 · Unsafe preview

This is the part that actually needs the opt-in. #preview renders whatever is in the source field above as live HTML via innerHTML — but only once it dispatches securitypolicyviolation and its own onsecuritypolicyviolation="event.anythingGoes = true" handler agrees, the same handshake of unsanitizedInnerHTML uses internally. Updates as you type, and once after a reload restores the source from the gist.
