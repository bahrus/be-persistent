The location.hash version stows raw markup in the URL. This one stows it in a secret gist and keeps only the pointer (#gistID:…) in the URL. Same opt-in: of unsanitizedInnerHTML plus an onsecuritypolicyviolation handler that sets event.anythingGoes = true.

1 · Get a GitHub token with the gist scope

Creating / updating a gist needs a token; reading a public gist does not. The token is stored only in this browser's localStorage (key fifteenthGistToken — the same one fifteenth's demos/gist.html uses, so a token pasted there on http://localhost:8000 is already picked up) and is sent only to api.github.com. Use whichever route is easier — the classic token is simpler (one checkbox).

Route A — classic token (recommended, ~30 seconds)
  1. Open github.com/settings/tokens/new?scopes=gist while signed in to GitHub. This is the “Tokens (classic)” screen and the link pre-fills the note and pre-ticks the one scope you need.
    Manual path if the link ever moves: your avatar (top-right) → Settings → far bottom of the left sidebar → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → Generate new token (classic).
  2. Set Expiration (e.g. 7 days — this is just a demo).
  3. Under Select scopes, confirm the top-level checkbox gist (“Create gists”) is ticked. Leave everything else unchecked — repo is not needed.
  4. Click Generate token at the bottom. Copy the value shown once — it starts with ghp_.
  5. Paste it below and press Save token.
Route B — fine-grained token (where “Account permissions” hides)
  1. Open github.com/settings/personal-access-tokens/new (Developer settings → Personal access tokens → Fine-grained tokens → Generate new token).
  2. Fill in Token name and Expiration.
  3. Set Resource owner to your own account.
    The “Account permissions” section does not appear until a Resource owner is selected, and it sits below the long “Repository permissions” list — scroll past all of those. It is a separate, collapsed group near the bottom of the page.
  4. You can leave Repository access on “Public repositories” or “No access” — gists are not repositories.
  5. Scroll to Permissions → Account permissions, find “Gists”, and change its dropdown from No access to Read and write.
  6. Click Generate token. Copy the value — it starts with github_pat_.
  7. Paste it below and press Save token.

If your account belongs to an organization that hasn't opted into fine-grained tokens, “Account permissions” can still be missing — use Route A in that case.

Revoke it any time at github.com/settings/tokens.

2 · Editable region — gist://unsafe-html-demo/markup.html

The region starts empty, so nothing is written until you type and leave it — no doomed create on load. Editing fires input on every keystroke; this rule uses on focusout instead so one gist PATCH is sent when you leave the region, not one per key. Reload the page — the innerHTML comes back from the gist.
