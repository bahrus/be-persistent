be-persistent → GitHub Pages

Both fields below are enhanced with 💾 and a githubpages:// USL. On change (blur / Enter) the value is committed straight to a file in your repo via the GitHub Contents API; on reload it is read back. Unlike gist://, the two fields live at real, nested paths in the repo — be-persistent-demo/greeting.json and be-persistent-demo/notes.json — not two files crammed into one flat gist.

2 · Persisted fields

Type something, click outside the field (fires change), then reload the page — the values come back from the repo. An empty field writes nothing (breakTie treats a blank element value as "nothing"), so no file is created until you enter a real value.
