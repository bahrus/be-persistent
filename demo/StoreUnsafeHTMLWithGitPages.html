2 · Source

Plain of value — an ordinary be-persistent rule; a <textarea>'s value is always text, so it never needs unsanitizedInnerHTML. The field starts empty, so nothing is written until you type and leave it. Typing fires input on every keystroke; this rule uses on focusout instead so one commit is made when you leave the field, not one per key. Reload the page — the text comes back from the repo.

Updates as you type, and once after a reload restores the source from the repo.
